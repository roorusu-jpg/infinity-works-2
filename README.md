# INFINITY WORKS II

**無限の生産、その先へ。**

SF世界を舞台にした、クリック＆放置型インクリメンタルゲームです。

## v0.1.0
- クリック／タップによるエネルギー生産
- 自動生産施設の購入と毎秒生産
- クリック出力アップグレード
- LocalStorageによる自動セーブ
- 最大8時間分のオフライン生産
- PC・スマートフォン対応レイアウト

## 開発環境
- HTML / CSS / JavaScript (ES Modules)
- GitHub
- Render Static Site

## ローカルでの起動
ES Modulesを使用しているため、VS CodeのLive ServerなどのローカルHTTPサーバーで `index.html` を開いてください。
