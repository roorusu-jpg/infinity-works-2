# INFINITY WORKS II

**無限の生産、その先へ。**

## v0.6.0
- 工場リストを初期4種類分の高さに制限し、追加工場はリスト内スクロールで表示
- 転生システムを追加
- 今回の累計生産量に応じて転生ポイントを獲得（1ポイント目の条件は累計10億）
- 転生ポイント1つにつきクリック出力・全工場生産量が恒久的に10%上昇
- 転生時はエネルギー、工場、通常強化をリセット。スキルツリーと転生強化は維持
- 既存セーブデータを引き継ぎ

## v0.5.0
- 自動生産工場を全20種類に拡張
- 最初は4種類を表示し、現在の最上位工場を10基購入すると次の工場を1種類ずつ解放
- スキルツリーを専用ページ（skill-tree.html）に分離
- 既存セーブデータと取得済みスキルを引き継ぎ

## v0.4.0
- 装置のまとめ買い（×1 / ×10 / ×25 / MAX）
- スキルツリーを各3段階、合計9スキルに拡張
- 既存セーブデータを引き継ぎ、新スキルは未取得状態で追加

## v0.3.0
- エネルギー収集ボタンのダブルタップズームを抑制（画面全体のピンチズームは維持）

SF世界を舞台にした、クリック＆放置型インクリメンタルゲームです。

## v0.2.0
- v0.1.0のクリック生産・自動生産施設・オペレーター強化
- LocalStorageによる自動セーブ
- 最大8時間分のオフライン生産
- 6種類のスキルを持つスキルツリー
- クリック出力・施設生産量・施設価格を恒久強化
- スキル取得状況と強化倍率をセーブデータに保存
- PC・スマートフォン対応

## 開発環境
- HTML / CSS / JavaScript (ES Modules)
- GitHub
- Render Static Site

## ローカルでの起動
ES Modulesを使用しているため、VS CodeのLive ServerなどのローカルHTTPサーバーで `index.html` を開いてください。

## 更新履歴
- **v0.6.0**：工場一覧のスクロール表示と転生システムを追加。
- **v0.5.0**：工場を20種類に拡張し、最上位工場10基購入ごとの段階解放とスキルツリー専用ページを実装。
- **v0.4.0**：装置のまとめ買い機能と3段階スキルツリーを追加。

- **v0.1.0**：クリック生産、自動生産施設、クリック強化、ローカルセーブ、オフライン生産を実装。
